# Security

Install official builds from this repository's release page or through 3DPCS Pack Manager. You can also inspect and build the source yourself.

Pack Manager checks that an official download matches the file published by 3DPCS. Modified builds can be installed through **Developer installs** after the user approves the exact file.

Native mods are trusted controller code, not sandboxed apps. Report security problems privately to the 3D Printed Controller Systems team.
